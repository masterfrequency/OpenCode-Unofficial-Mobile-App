    OPENCODE UNOFFICIAL

    Connection setup

    First: install the gateway

    The gateway is a separate companion service. It does not replace or modify OpenCode. Transfer the installer to the same computer or VPS where OpenCode is installed.

    The installers check OpenCode, Node.js, and Tailscale, then configure the gateway and pairing code.
    RECOMMENDED · VPS OR HOME PC
    1. Install OpenCode, Node.js 20+, and Tailscale on the Linux PC or VPS. Install Tailscale on this Android phone and sign both into the same tailnet.
    2. Tap Save Debian / Ubuntu package, transfer the .deb to the Linux machine, then run:
      sudo apt install ./opencode-unofficial-gateway_1.1.0_all.deb
opencode-unofficial-setup
    3. The setup checks the required programs, installs the gateway separately from OpenCode, enables automatic startup, configures Tailscale Serve, and prints the pairing code.
    4. Create a profile, enter the displayed HTTPS URL and six-digit code, then tap Pair and test connection.
    VPS tip

    Tailscale avoids opening public firewall ports. OpenCode stays on 127.0.0.1:4096.

    Owner recovery

    Promote a second owner under Edit connection → Manage paired devices. If every owner is lost, run node device-admin.mjs list and node device-admin.mjs promote DEVICE_ID locally in the installed gateway folder.

    WINDOWS PC · POWERSHELL
    1. Install OpenCode, Node.js 20+, and Tailscale on the Windows PC. Install Tailscale on this Android phone too, then sign both devices into the same tailnet.
    2. Tap Save Windows installer, transfer the .exe to the Windows PC, verify the publisher signature, and run it.
    3. The installer checks OpenCode, Node.js, and Tailscale; installs the gateway separately under your local application data; configures startup and Tailscale Serve; and prints the HTTPS address and pairing code.
    4. Enter the HTTPS URL and six-digit pairing code in a new connection profile, then tap Pair and test connection.
    Where is the pairing code?

    It is printed in the gateway window and saved in gateway\.pairing-code. It expires after one hour and works once. Restart the gateway for a new code.

    Adding more phones

    Restart the gateway for a fresh code before pairing each phone. The first phone is the owner and can revoke later phones under Edit connection → Manage paired devices.

    Portable fallback

    If your system cannot use the installer, save the portable ZIP and extract it into its own writable folder—never over OpenCode itself.

    Owner recovery

    Promote a second owner under Edit connection → Manage paired devices. If every owner is lost, run node device-admin.mjs list and node device-admin.mjs promote DEVICE_ID locally in the gateway folder.

    Windows Firewall

    Do not open ports 4096 or 4174 publicly. Tailscale reaches the loopback-only gateway without router port forwarding.

    PUBLIC VPS WITH HTTPS
    1. Start the gateway using the commands above.
    2. Point your domain to the VPS.
    3. Install Caddy and copy gateway/Caddyfile.example.
    4. Replace code.example.com with your domain and reload Caddy.
    5. Use https://your-domain in the app.
    Never expose port 4096

    Only the authenticated gateway on port 4174 should sit behind HTTPS.

    HOME NETWORK

    Android blocks insecure HTTP by design. The simplest supported home setup is still Tailscale because it gives you a trusted HTTPS address without router configuration.

    If you operate your own local certificate authority, put an HTTPS reverse proxy in front of port 4174 and install its CA on Android.

    ACCESS CONTROL

    Paired devices

    Every phone has a separate encrypted credential. An owner can revoke a lost or retired device without disconnecting everyone else.
