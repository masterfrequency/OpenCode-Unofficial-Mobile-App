# Code of Conduct

## The short version

Be civil. Assume good faith. No harassment.

## Standards

**Expected:**

- Be respectful and considerate. Disagreement is fine; contempt is not.
- Assume the other person is competent and acting in good faith.
- Accept constructive criticism gracefully, and give it kindly.
- Take responsibility when you get something wrong.

**Not acceptable:**

- Harassment, intimidation, or discrimination of any kind
- Personal attacks, insults, or name-calling
- Sexualised language or imagery
- Publishing others' private information without explicit permission
- Sustained disruption of discussions
- Abuse of project infrastructure — do not use issues for promotion or spam

## Scope

This code applies in all project spaces: issues, pull requests, discussions, and release notes. It also applies when an individual is officially representing the project in public.

## Enforcement

Report unacceptable behaviour by opening a confidential report through [GitHub Security Advisories](https://docs.github.com/en/code-security/security-advisories), or by contacting the maintainer directly.

Maintainers may remove, edit, or reject contributions that do not align to this Code of Conduct, and may block or ban contributors whose behaviour is inappropriate, threatening, offensive, or harmful.
